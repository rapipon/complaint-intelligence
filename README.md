# Complaint Intelligence

NLP-система для интеллектуальной обработки обращений клиентов.

## About The Project

Complaint Intelligence — ML-система, предназначенная для помощи сотрудникам службы поддержки при обработке клиентских обращений.

Система получает текст обращения и автоматически:

- определяет продукт и проблему;
- оценивает уверенность модели;
- находит похожие исторические обращения;
- помогает определить дальнейшую маршрутизацию;
- предоставляет данные для оценки потенциального бизнес-эффекта.

Основная идея проекта — не полностью заменить сотрудника поддержки, а сократить объём рутинной ручной работы и ускорить принятие решений.

## Dataset

В качестве источника данных используется **CFPB Consumer Complaint Database** — публичная база исторических обращений потребителей.

Датасет содержит тексты обращений и связанную с ними структурированную информацию.

Перед обучением моделей данные будут исследованы и подготовлены с учётом:

- пропущенных значений;
- дисбаланса классов;
- качества текстовых данных;
- возможной утечки данных;
- временной структуры данных.

## Machine Learning

### Complaint Classification

Основная ML-задача — определить категорию проблемы по тексту обращения.

В качестве первого baseline используется:

```text
TF-IDF + Logistic Regression
```

После получения baseline будут исследованы более сложные подходы, если они способны дать существенное улучшение качества.

### Semantic Search

Вторая задача — поиск исторических обращений, похожих на новое обращение по смыслу.

Для этого будут использоваться текстовые embeddings и поиск ближайших примеров.

### Evaluation

Основные метрики:

- Macro F1
- Weighted F1
- Precision
- Recall
- Confusion Matrix

Для финальной оценки по возможности будет использоваться временное разделение данных: обучение на более старых обращениях и тестирование на более новых.

## Getting Started

### Prerequisites

Для запуска проекта потребуется:

- Python;
- uv;
- Git.

### Installation

Клонировать репозиторий:

```bash
git clone <repository-url>
cd complaint-intelligence
```

Установить зависимости:

```bash
uv sync
```

Запустить проект после завершения разработки:

```bash
uv run ...
```

Команда запуска будет уточнена после реализации API и пользовательского интерфейса.

## Usage

Пользователь сможет передать системе текст клиентского обращения и получить:

- категорию обращения;
- уверенность модели;
- похожие исторические обращения;
- рекомендуемую маршрутизацию;
- дополнительную информацию для принятия решения.

Пример пользовательского сценария:

```text
1. Пользователь вводит текст обращения.
2. Система анализирует текст.
3. ML-модель определяет категорию.
4. Semantic Search находит похожие обращения.
5. Система формирует итоговый результат.
6. Сотрудник принимает окончательное решение.
```

## Business Impact

Проект предполагает оценку не только качества ML-моделей, но и потенциальной экономической эффективности системы.

Будут оцениваться:

- доля обращений, которые можно автоматически классифицировать;
- время, сэкономленное сотрудниками;
- потенциальное снижение стоимости обработки;
- стоимость ошибок классификации и маршрутизации;
- потенциальная ежемесячная экономия.

Финансовая модель будет основываться на явно указанных предположениях.
